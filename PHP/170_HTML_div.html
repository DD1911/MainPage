Das HTML-Element div

Das div-Element steht für Division (= Bereich).
Es wird genutzt, um Inhalte in Blöcke einzuteilen.
Ein div ist standardmäßig so breit wie das Browserfenster und so hoch wie sein Inhalt.
Mit CSS kann man Größe, Rahmen, Abstände und Farben anpassen.

Ich bin im zweiten div.
Die Ränder können unterschiedlich dick sein.

danach geht es im Uhrzeigersinn weiter (rechts, unten, links).
